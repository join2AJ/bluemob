Before you start

  • Install the same APK (0.11.0) on every phone. Check under You → About.
  • On each phone allow Nearby devices, Location, Notifications, and Microphone + Camera when asked for a call.
  • Turn Bluetooth and Location on. Wi-Fi on (no network needed). Mobile data off unless a check says otherwise.
  • Distances: "side by side" is under 2 m, "apart" is another room or 20–50 m outdoors, "out of range" is 150 m+ outdoors or several walls.
  • If something fails, note the time. Then on that phone open You → Connections → Mesh log and screenshot it.
