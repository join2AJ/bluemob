# Internal test (one week, 10 to 20 people)

## Set-up

1. Play Console → Testing → Internal testing → create a release with the `.aab`, add testers by email, share the link.
2. Group testers in pairs or threes who can meet in person, plus a few far apart (different cities).
3. Ask everyone to turn on **You → Diagnostics → Send error reports automatically** and to use
   **Report a problem** (with screenshots) for anything odd.

## Day 1: set up (everyone)

- [ ] Sign up, add an SOS contact, set a PIN.
- [ ] Switch to Hindi (You → Language) and back. Note any wrong or missing Hindi.
- [ ] Turn on the emergency card; lock the phone; the card shows.

## Days 2–3: in pairs, together

- [ ] See each other on Nearby with Wi-Fi and mobile data **off**.
- [ ] Message, voice note, photo; check the ticks.
- [ ] Voice call and video call with no internet.
- [ ] Verify each other with the QR code; the ✓ shows in the chat.
- [ ] One sends an SOS (preview first: SOS → Preview); the other gets the alarm, taps I'm coming, follows the compass.
- [ ] The sender taps I'm safe; the rescue group closes on both phones.
- [ ] Power button SOS: turn it on, press 5 times, cancel within 5 seconds. Then once without cancelling, and end it.

## Days 4–5: apart

- [ ] Message and call across cities over the internet, with the app closed on the receiving phone.
- [ ] Check-in timer for 1 hour; let it run out; the SOS contact gets the alert.
- [ ] Fall detection on: drop the phone onto a bed from chest height and leave it 15 seconds; cancel the countdown.

## Days 6–7: daily use

- [ ] Use it normally with Background on. Note battery use per day (Settings → Battery).
- [ ] Read 3 guides (one aloud in Hindi), pass a quiz, check badges and level.

## What to send back

- Phone model and Android version.
- What didn't work, with a screenshot (Report a problem).
- What was confusing, and one thing you'd change.
- Battery percentage used by BlueMob per day.
